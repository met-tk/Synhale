# Granular Acoustic Sample Library - Candidate Manifest

本目录用于存放 Synhale 2 物理微粒合成（Granular Channel）所使用的真实声学采样音频。
所有音频均为 100% 真实物理实录（Real Acoustic Recordings），绝无任何代码或数学公式伪造生成的噪声。

您可随时在磁盘中试听并手动筛选/删除不喜欢的素材。筛选完成后，系统将针对您留下的素材进行均一化与响度校准，并自动接入采样预设。

## 4. 手动筛选与操作指南

1. **直接试听**：您可直接使用系统播放器打开本目录（`public/audio/granular/`）下的任意音频进行试听。
2. **删除或替换**：
   - 若某些音频您认为音色不符合预期，可直接**从磁盘删除**对应文件；
   - 若您有更优质的同名或自定义音频，亦可直接覆盖或放入本目录中。
3. **通知执行**：完成筛选后，向助手回复确认，助手将读取留存的文件完成响度均一化并绑定到 Granular 采样引擎。
