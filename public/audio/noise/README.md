# OSC B Noise Channel - Candidate Manifest

本目录用于存放 Synhale 2 呼吸气道摩擦与噪音发生器（OSC B Channel）所使用的真实录音噪音素材。
所有音频均为 100% 真实物理实录（Real Acoustic / Studio Analog Recordings），完全切除了原代码中 `Math.random()` 程序化伪合成噪声。

您可随时在磁盘中试听并手动筛选/删除不喜欢的素材。筛选完成后，系统将针对您留下的素材进行无缝等功率边界交叠（Seamless Looping Crossfade）与均一化校准。

## 3. 手动筛选与操作指南

1. **直接试听**：您可直接使用系统播放器打开本目录（`public/audio/noise/`）下的任意音频进行试听。
2. **删除或替换**：
   - 若某些音频您认为听感不符合预期，可直接**从磁盘删除**对应文件；
   - 若您有自己收藏的真实噪音录音，也可直接改名放入对应文件名。
3. **通知执行**：完成筛选后，向助手回复确认，助手将对留下来的音频进行统一的 50ms 等功率循环无缝拼接（Seamless Loop Crossfade）与响度均一化，并彻底在 `OscBChannel.ts` 中废除 `Math.random()`。
